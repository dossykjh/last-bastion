# LAST BASTION — 마지막 보루

스타크래프트2에서 영감을 받은 3D 타워디펜스 웹게임(비공식 팬메이드, Blizzard Entertainment 와 무관).
테란이 협곡 길목을 막고 저그 떼가 몰려온다. 폰 가로 화면 기준.

**플레이:** https://dossykjh.github.io/last-bastion/
폰에서는 브라우저 메뉴의 「홈 화면에 추가」로 설치하면 가로 전체화면으로 실행된다.

- 3D 모델: Tripo AI 로 제작 · 지형 질감: Poly Haven (CC0)
- 이 저장소는 빌드 결과물이다 (원본은 비공개 작업 폴더).
